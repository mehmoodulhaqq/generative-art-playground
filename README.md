# Generative Art Playground

A creative web application that allows users to generate beautiful abstract artwork using different visual styles, colors, and customization settings.

## Overview

Generative Art Playground is an interactive JavaScript project built with HTML, CSS, and JavaScript. Users can experiment with different art styles, customize colors and backgrounds, adjust artwork complexity, and download their creations.

## Features

- Four generative art styles:
  - Geometric
  - Waves
  - Particles
  - Patterns
- Custom color selection
- Multiple background options
- Adjustable artwork complexity
- Random artwork generation
- Reset settings to defaults
- Download generated artwork as an image
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- HTML Canvas API
- JavaScript ES Modules

## Getting Started

### Run Locally

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder in your code editor.

3. Run the project using a local development server, such as the VS Code Live Server extension.

4. Open the local URL provided by the server.

**Note:** A local server is recommended because the application uses JavaScript ES modules.

## How to Use

1. Open the homepage.
2. Navigate to the Art Studio.
3. Select an artwork style.
4. Customize colors and background.
5. Adjust the complexity.
6. Generate or randomize your artwork.
7. Download your creation.
